# AI-Powered Customer Support & Service Automation

## Project Overview
This project demonstrates how Salesforce can improve customer support through custom data management, case assignment automation, and AI-assisted case summaries.

## Objectives
- Organize customer, product, order, and support case information.
- Automate support case assignment using Salesforce Flows.
- Generate AI-assisted summaries for support cases.
- Provide reports and dashboards for case analysis.
- Improve maintainability and visibility of support operations.

## Salesforce Components

### Custom Objects
- **Customer:** Stores customer details, including email, phone, and customer type.
- **Merchandise:** Stores product information, category, product code, warranty, and active status.
- **Orders:** Stores order number, date, status, customer, and product relationships.
- **User Case:** Stores support case details, priority, case type, issue category, related order and product, and AI Summary.

### Automation
- Case assignment flows for support routing.
- Damage Support Queue and Warranty Support Queue.
- AI Summary generation through Salesforce Prompt Builder.

### Reports and Dashboards
- Customer Support Case Analysis report.
- Customer Support Dashboard for visualizing case information.

## Testing
The project uses sample records to demonstrate object relationships, case details, AI Summary generation, and reporting.
